# Olist E-Commerce Analytics Project

End-to-end business analytics project built on the Olist Brazilian E-Commerce dataset using Python, PostgreSQL, SQL, and Power BI.

## Project Overview

This project simulates the workflow of a real-world data analyst working with transactional e-commerce data. The pipeline includes data ingestion, cleaning, database modeling, SQL analytics, customer retention analysis, RFM segmentation, and dashboard development.

The dataset contains 100k+ orders across 9 relational tables covering customers, orders, payments, products, reviews, and sellers.

## Tech Stack

- Python
- pandas
- PostgreSQL
- SQLAlchemy
- SQL
- Power BI
- Jupyter Notebook

## Current Features

- ETL pipeline for loading and cleaning raw CSV data
- PostgreSQL database schema and table creation
- Analytical SQL queries using joins, CTEs, and window functions
- Exploratory Data Analysis (EDA)
- Cohort retention analysis
- RFM customer segmentation
- KPI and dashboard development
